# AI Policy

A high bar is held for all contributions to this project. The project maintainers remain responsible for any code and content published as part of a release. Contributors are responsible for any code and content they publish. Pull requests, issues, and comments that appear in violation of this policy will be closed or hidden, potentially without notice.

This project always requires a human in the loop who understands any work produced by AI. **Autonomous agents are not allowed to be used for contributing to this project.**

Contributors should remain alert to biases, discriminatory logic, or fairness issues in AI-generated output. AI use should be conscious and intentional, considering environmental impact, energy consumption, and the human time required for meaningful oversight and review.

---

### Code Contributions

Using AI (i.e., LLMs) as tools for coding is welcome. Use of AI tools in creating your contributions must be disclosed, and contributions must be reviewed and verified by you for compliance with applicable third-party licenses and intellectual property rights.

### Communication

AI may be used to assist when communicating with maintainers and the community, but you are ultimately accountable for everything you contribute. You must fully review and understand any AI-generated content before posting it and ensure the content is actionable by humans. Pull request descriptions, issues, and comments are primarily meant for humans and must be presented in an appropriate format. **Do not copy full AI responses when communicating with maintainers and contributors without disclosing them as such.**

- If you are opening a pull request, you are expected to be able to explain the proposed changes in your own words, including the pull request body and responses to questions.
- If you are opening an issue, you should be able to describe the problem in your own words.
- If you wish to include context from an AI interaction in your comments, issues, or pull requests, it must be in a quote block (e.g., using `>`) and disclosed as such. It must be accompanied by human commentary explaining the relevance and implications. Avoid sharing long snippets — share relevant parts only.
- If using AI for translation, we recommend writing in your native language and including the AI translation in a quote block.
- If you're using AI for editing content as a non-native English speaker, please take the time to ensure the meaning and intent accurately reflect your own ideas.
